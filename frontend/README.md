# DRONA-LOG frontend

React 19 + Vite + Tailwind CSS + MapLibre GL. See the [root README](../README.md)
for the architecture, demo script, API and test instructions.

```bash
npm install
npm run dev      # http://localhost:5173, /api proxied to http://localhost:8000
npm run build    # production bundle in dist/
npx vitest run   # hash-chain parity tests
```
